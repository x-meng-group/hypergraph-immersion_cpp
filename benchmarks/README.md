# Benchmarks

This directory is reserved for repeatable performance cases.

Planned benchmark groups:

- `small/`: hand-checkable fixtures
- `medium/`: typical research cases
- `hard/`: cases that stress the C++ search
- `random/`: generated hypergraphs with recorded seeds
- `paper_examples/`: examples used in papers or notebooks

Each benchmark should record the number of vertices, hyperedges, max edge size, solver mode, result, runtime, and memory notes.
